      About this tool

      This password generator creates random passwords using the character types you select. All processing happens locally in your browser — the password is never transmitted anywhere. For best security, use a password manager to store passwords you generate here.

      How to use it

      1. Drag the Length slider to set password length (4–128 characters).
      2. Check which character types to include.
      3. Click Generate. A strength indicator will appear.
      4. Click Copy to copy the password to your clipboard.

      FAQ

      Is this secure enough for real passwords?
      The generator uses Math.random(), which is not cryptographically secure. For high-security needs, use your browser's built-in password manager or a dedicated tool that uses crypto.getRandomValues(). For most everyday use, a long password from this tool is still far better than a weak one.
      What does "Exclude ambiguous" do?
      It removes characters that look similar — 0 and O, 1 and l and I — to make the password easier to read and type manually.
      What is the maximum length?
      Up to 128 characters.
