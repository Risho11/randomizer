    About this tool

    This tool picks random letters from the standard A–Z alphabet or from a custom set you define. You can get one letter or many, in uppercase, lowercase, or a random mix of both.

    How to use it

    1. Choose A–Z (standard) or Custom alphabet. If custom, type the letters you want to include.
    2. Select the case — uppercase, lowercase, or mixed.
    3. Enter how many letters you want.
    4. Click Generate.

    Common uses

    • Picking Scrabble or Boggle tiles
    • Word game starters and creative writing prompts
    • Teaching the alphabet or spelling patterns
    • Building simple codes or substitution ciphers
    • Randomly assigning groups a label (Team A, Team B…)

    FAQ

    Can I use only vowels or consonants?
    Yes — select Custom alphabet and type just the letters you want to draw from (e.g. AEIOU for vowels only).
    Does it allow repeated letters?
    Yes. Each letter is drawn independently, so the same letter can appear more than once.
    What is the maximum count?
    Up to 100 letters at a time.
