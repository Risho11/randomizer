      About this tool

      Paste any list of items (one per line or comma-separated) and pick a random subset. Weight individual items with the :N syntax — add :3 after an item to give it 3× the probability of being picked (e.g. Alice:3). Enable shuffle mode to randomize the entire list in order instead of picking a subset. Toggle allow-duplicates to permit the same item to be picked more than once. Filter items containing a keyword before picking.

      Common uses

      • Running giveaways and raffles with weighted entries
      • Picking a random winner from a list of names
      • Choosing a random restaurant, movie, or activity
      • Randomizing a playlist or reading list order
      • Teacher picking random students to answer questions

      FAQ

      Can I pick multiple winners from my list?
      Yes — set How many to pick to any number. Each pick is unique (no repeats) unless you enable Allow duplicates.
      Can I shuffle the entire list instead of picking?
      Check Shuffle full list to randomize all items in order instead of selecting a subset.
      Does it work for giveaways and raffles?
      Yes. Paste your list of entrant names, set count to 1 (or more for multiple winners), and click Pick.
      Can I give some items a higher chance of being picked?
      Open Advanced options and enable Weight with :N syntax. Add :3 after an item to triple its odds, e.g. Alice:3.
