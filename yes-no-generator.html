      About this tool

      This is a simple, fair random yes/no generator. Each click picks an answer with equal probability — 50% yes, 50% no. When you enable Maybe, each answer has a one-in-three chance.

      It is useful any time you want an unbiased external answer, without flipping a physical coin.

      How to use it

      1. Choose how many answers you want (default is 1).
      2. Check Include Maybe if you want a three-way result.
      3. Click Generate.

      • Replacing a coin flip

      FAQ

      Is it truly 50/50?
      Yes. The generator picks from an array of [Yes, No] with equal probability. With Maybe enabled it is [Yes, No, Maybe] — each roughly 33%.
      Can I get multiple answers at once?
      Yes, up to 20 answers in a single click.
      Can I use this for important decisions?
      It is random — that is the point. For anything consequential, use it as a tie-breaker, not the sole input.
