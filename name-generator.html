      About this tool

      This name generator draws from a list of common English first and last names, plus fantasy-style invented names. It is useful for generating realistic-sounding names quickly without having to think one up yourself.

      The Fantasy option produces invented names suitable for characters in fiction, worldbuilding, or games. The Gender-neutral option uses names that are commonly used for any gender.

      How to use it

      1. Choose a Name type — full name, first name only, fantasy, or neutral.
      2. Select a Gender preference, or leave it on Any for a mix.
      3. Set how many names you want.
      4. Click Generate.

      FAQ

      Are these real names?
      The first and last name lists are drawn from common English names. Fantasy names are invented and do not correspond to real people.
      What does "Gender-neutral" mean here?
      It picks from a list of names that are widely used regardless of gender — names like Alex, Jordan, Riley, and similar.
      Does the gender filter apply to fantasy names?
      No. Fantasy names are generated from a single pool without gender assignments since they are invented.
      Can I generate a large batch?
      Yes, up to 50 names at once.
