      About this tool

      Enter any set of options and it picks one at random. Think of it as a digital wheel spin — without the wheel. Each pick is made without replacement, so if you pick more than one you will not get the same item twice.

      Common uses

      • "What should we eat tonight?" — paste restaurants
      • Random movie or show to watch
      • Assigning tasks or chores
      • Choosing who goes first in a game
      • Creative prompts and writing starters

      FAQ

      What can I use this for?
      Anything that requires a random pick — restaurants, movies, chores, who goes first in a game, creative writing prompts, or any decision.
      Can I pick multiple items at once?
      Set How many to pick to any number. Each item is picked once (no repeats) unless Allow duplicates is on.
      What is wheel-down mode?
      Enable Remove picked (wheel-down mode) in Advanced options. Each pick removes the item from the pool, like drawing without replacement.
      Can I give some options a higher chance?
      Open Advanced options and enable Weight with :N syntax. For example, Pizza:3 gives Pizza 3× the normal probability.
