      About this tool

      Enter any list of options and let the tool pick randomly. Weight options with the :N syntax (e.g. Pizza:3 gives Pizza 3× the odds). Enable elimination mode (wheel-down) to remove each picked item from the pool — like drawing from a hat without replacement. Useful for any choice where you want to work through all options before repeating. Toggle allow-duplicates if you want the same option to be picked multiple times.

      Common uses

      • Picking a restaurant, movie, or activity when you can't decide
      • Running random order for presentations or turns in a game
      • Eliminating options one-by-one until a final choice remains
      • Randomizing a to-do list order
      • Settling arguments with a fair random pick

      FAQ

      What can I use this for?
      Anything that requires a random pick — restaurants, movies, chores, who goes first in a game, creative writing prompts, or any decision.
      Can I pick multiple items at once?
      Set How many to pick to any number. Each item is picked once (no repeats) unless Allow duplicates is on.
      What is wheel-down mode?
      Enable Remove picked (wheel-down mode) in Advanced options. Each pick removes the item from the pool, like drawing without replacement.
      Can I give some options a higher chance?
      Open Advanced options and enable Weight with :N syntax. For example, Pizza:3 gives Pizza 3× the normal probability.
