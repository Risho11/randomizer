      About this tool

      This random number generator produces numbers using your browser's built-in random function. You can generate one number or a batch, work with integers or decimals, and restrict results to a custom range.

      All generation happens locally — no data is sent anywhere.

      How to use it

      1. Set the Min and Max values for your range.
      2. Choose how many numbers you want.
      3. Check Integers only for whole numbers, or uncheck it for decimals.
      4. Click Generate. Use Generate Again for a new result without changing settings.
      5. Use Copy to copy the result to your clipboard.

      FAQ

      How random is this generator?
      It uses Math.random(), which is a pseudo-random number generator. It is suitable for games, decisions, and general use. It is not cryptographically secure — do not use it for security-sensitive applications.
      Can I generate decimal numbers?
      Yes. Uncheck Integers only and set the number of decimal places you want.
      What happens if I ask for more unique numbers than the range allows?
      The tool will show an error explaining the limit. For example, you cannot pick 10 unique integers from a range of 1–5.
      What is the maximum number of results?
      You can generate up to 200 numbers at a time.
